# 3D 机模制作说明（二）：刘海机型全系 + 现有模型细化

交给 Codex / Blender MCP。先读 `docs/3d-model-brief.md` 和 `assets/model/README.md`，本说明只写新增和不同的部分；
坐标、单位、命名、材质规则没有另外说明的都沿用它们。

## 任务

1. **细化现有模型** `assets/model/macbook-pro-14.blend`（14 寸 PROLED，灵动岛）。
2. **新做四个刘海机型**，每个机型一套独立文件：

| 文件名前缀 | 机型 | 适用年份 | 风扇 | 备注 |
|---|---|---|---|---|
| `macbook-pro-14-notch` | MacBook Pro 14 寸 | 2021–2025（M1 Pro 至上一代） | 2 | 刘海 |
| `macbook-pro-16-notch` | MacBook Pro 16 寸 | 2021–2025 | 2 | 刘海，6 块电芯排布与 14 寸不同，按拆机图 |
| `macbook-air-13` | MacBook Air 13 寸 | M2 及以后 | 0 | 刘海，无风扇、无热管，被动散热片 |
| `macbook-air-15` | MacBook Air 15 寸 | M2 及以后 | 0 | 同上，扬声器为 6 个 |

更老的机型（无刘海的 Intel / M1 机身）不做。同一机身跨多代芯片的，只做一个模型，内部布局取其中资料最全的一代，
并在 README 里写明是哪一代。

## 每个机型都要先查的资料

- Apple 官方技术规格：合盖宽、深、厚，屏幕分辨率和 ppi（换算显示区尺寸），重量不需要。
- iFixit 或同类拆机图：电芯数量和排布、主板轮廓、SoC 位置、SSD 位置、风扇直径和位置（Pro）、热管走向（Pro）、
  散热片（Air）、扬声器、两侧接口（MagSafe、雷雳、HDMI、SD、耳机孔各在哪一侧）。
- 存到 `assets/reference/<文件名前缀>/`，**不要提交进 Git**（该目录已被忽略）。README 里只写来源链接。
- 查不到的尺寸按照片透视校正估算，并在 README 里标明"估算"。不要凭印象填数字。

## 与 PROLED 机型不同的地方（四个新机型都适用）

- **屏幕顶部是刘海**：摄像头模组与上边框相连，不是悬浮药丸。开盖时要能看出来。单独做成物体 `Display_Notch`。
- **顶盖 logo 不发光**：镜面抛光金属。仍然是独立物体 `Logo`、独立材质，但 Emission 为黑，Metallic 1、Roughness 约 0.1。
- **颜色**：Pro 用深空黑或深空灰，Air 用午夜色。只做一种颜色。
- **Air 没有风扇**：不要出现 `Fan_*` 和 `Heatpipe` 节点。散热片命名 `Heatsink`。App 发现没有 `Fan_L_Rotor` 就不画风扇和气流。
- **Air 的芯片只分两块**：`Die_Perf`（性能核）、`Die_GPU`；没有 `Die_Super`。Pro 刘海机型同样没有 Super 核，
  用 `Die_Perf`、`Die_Eff`（能效核）、`Die_GPU`。
- **电芯数量按实际**：`Battery_Cell_0` 起从左到右编号。Air 13 寸是 4 块，其余以拆机图为准。

节点命名总表（App 按名字查找；没有的部件就不要建，不要留空节点）：

`Shell_Lid`、`Shell_Bottom`、`Chassis_Rail`、`Lid_Hinge`（顶盖、屏幕、Logo、Display_Notch 都挂在它下面，绕它开合）、
`Logo`、`Display_Notch`、`Board`、`SoC_Package`、`Die_Super` / `Die_Perf` / `Die_Eff` / `Die_GPU`、`SSD_0`、`SSD_1`、
`Fan_L_Housing`、`Fan_R_Housing`、`Fan_L_Rotor`、`Fan_R_Rotor`、`Heatpipe`、`Heatsink`、`Battery_Cell_N`、
`Speaker_L`、`Speaker_R`、`Ports_L`、`Ports_R`。

底壳材质里要保留一个名为 `Bottom_case_opacity` 的材质（App 用它把底壳调成半透明），刻字材质名为 `Laser_etch`。
这两个名字和现有模型一致，不能改。

## 细化要求（现有模型和四个新模型都按这个标准）

App 现在只在翻面和开合时才渲染，平时是静帧，所以面数预算放宽：**整机 ≤ 80,000 三角面，材质 ≤ 32**。
把预算花在看得见的地方，按优先级：

1. **底面透视视图**（最重要，温度热力图和气流画在这一面）
   - 风扇：扇叶数量、弯曲方向、轮毂和外框按拆机图；蜗壳出风口朝向正确。
   - 热管和鳍片：鳍片做成一排薄片而不是一整块。
   - 主板：屏蔽罩、连接器、SoC 周围的电源芯片用低矮的方块表示出层次，不需要逐个元件。
   - 电芯：有圆角、有接缝和排线，不是纯方块。
   - 底壳内侧的加强筋、螺丝柱、四个脚垫。
   - 芯片装在主板**朝底壳的一面**（现有模型装在朝顶盖的一面，从底面看被主板挡住，App 只能把主板调半透明来凑合，请改过来）。
2. **顶盖面**：四边的圆角和倒角、logo 的轮廓精度（曲线不能有折角）、铰链处的缺口。
3. **开盖姿态**：键盘每个键帽独立可见（可以是一个网格）、触控板、扬声器开孔、屏幕黑边和刘海/灵动岛、铰链筒。
4. **两侧接口**：开孔形状和位置准确。

不要做：贴图、程序化节点、骨骼、灯光、相机、屏幕内容（屏幕保持熄屏）。

## 动画

每个模型只需要静态网格，**不要烘焙动画**。开合和风扇旋转由 App 驱动：
- `Lid_Hinge` 的原点必须在铰链轴上，绕本地 X 轴转动，0° 为合盖。
- 风扇转子原点在圆心，绕本地 Y 轴转动。

现有 PROLED 模型里的 11 秒 `Inspection_Loop` 可以保留在 `.blend` 里，但导出的 `macbook-pro-14.usdz` 不要带动画。
